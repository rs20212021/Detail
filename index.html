Project Title: AI-Powered Retrieval-Augmented Generation (RAG) Customer Support Agent
Organization: E&ICT Academy, IIT Kanpur
Role: Trainee
Generative AI Technology used: Langchain, DPR (Dense Passage Retrieval), FAISS, FLAN-T5 (Seq2Seq), Streamlit, PyTorch (CUDA/CPU)
Project Details & Responsibilities
 Problem Addressed: Traditional rule-based chatbots lack scalability, while standalone LLMs frequently hallucinate or provide outdated answers due to a lack of enterprise data access.
Core Objective: Design and implement a scalable, Python-based AI customer support agent utilizing Retrieval-Augmented Generation (RAG) to deliver accurate, grounded, and explainable responses.
Key Goals:
Build a domain-aware RAG architecture.
Minimize hallucinations by grounding answers in verified documents.
Automate resolutions for repetitive customer queries.
Ensure a modular, production-ready project structure.
Evaluate performance metrics against real-world standards.
System Architecture & Key Modules:
Data Layer (data/): Stores raw support documentation (FAQs, manuals, policies), manages cleaned and chunked versions for embeddings, and separates raw data from processed outputs.
Embedding Layer (embeddings/): Converts document chunks into vector embeddings and stores them in a vector database (such as ChromaDB or FAISS) to power semantic retrieval.
Retrieval Layer (retriever/): Executes similarity searches based on user queries, fetches top-$k$ relevant document chunks, and controls retrieval depth.
LLM Layer (llm/): Defines prompt templates, manages interactions with models (OpenAI, Gemini, or Claude), and produces context-backed final responses.
RAG Pipeline (rag_pipeline/): Orchestrates the complete end-to-end flow (query intake, context retrieval, prompt construction, and response generation) alongside built-in fallback logic.
Evaluation Module (evaluation/): Measures system accuracy, relevance, response latency, and hallucination rates while benchmarking against baseline LLM-only models.
Interface Layer (interface/): Provides a user-facing web/API application for real-time interaction, extensible for agent dashboards and CRM integrations.
